# 上架审核准备（AppGallery）

> 老师反馈里的「没涉及到 AI 会更简单」是对的：本项目不做生成式 AI、
> 不做深度合成、不做 AI 内容推荐，因此不需要算法备案、深度合成标识、
> AI 内容安全专项等额外材料。审核重点回到「隐私 + 权限 + 内容 + 账号」。
>
> 华为的审核规则会更新，提交前以 AppGallery Connect 最新文档为准；
> 本文是课程项目的准备清单，不是官方合规意见。

## 1. 本项目为什么审核路径更短

| 维度 | 本项目 | 带来的简化 |
| --- | --- | --- |
| 生成式 AI | 不使用 | 不需要算法备案 / 深度合成标识 / AI 内容安全专项 |
| 用户生成内容 | 社团简介、活动简介、消息（文本） | 仍需要文本审核 / 举报入口，但不涉及图片 / 视频生成 |
| 支付 | 不涉及 | 不需要支付资质、分成、退款流程 |
| 位置 / 通讯录 / 相册 | 不采集 | 权限清单很短 |
| 账号体系 | 学号 + 密码（演示） | 需要隐私政策、账号注销、数据删除 |
| 数据存储 | 华为云数据库 | 数据在境内，减少跨境合规问题 |

## 2. 权限最小化

当前 `module.json5` 只申请：

```json
"requestPermissions": [
  { "name": "ohos.permission.INTERNET" }
]
```

后续按功能逐项加，且必须在使用时申请、在隐私政策里说明：

| 功能 | 权限 | 什么时候加 | 说明 |
| --- | --- | --- | --- |
| 网络请求 | `ohos.permission.INTERNET` | 已有 | 访问云侧 API |
| 活动提醒 | 通知授权（系统弹窗） | W7 | 首次进入消息中心时申请，不强制 |
| 扫码签到 | `ohos.permission.CAMERA` | 可选扩展 | 只有负责人 / 签到页使用，使用时申请 |
| 图片上传 | 相册 / 文件选择器 | 可选扩展 | 用系统 Picker，不申请全量相册权限 |

不要申请：通讯录、位置、麦克风、后台定位、读取应用列表。

## 3. 隐私与用户数据

必须准备：

- **隐私政策**：收集哪些字段（学号、姓名、学院、手机号）、用途、保存期限、
  共享对象（华为云数据库）、用户权利（查询 / 更正 / 删除 / 注销）。
- **用户协议**：社团 / 活动内容规范、违规处理、免责声明。
- **个人信息收集清单**：在 AppGallery 隐私标签里逐项填写。
- **账号注销**：应用内可发起，云侧删除或匿名化个人数据；社团历史数据按
  学校要求保留的，要说明保留范围和期限。
- **数据删除**：注销后 token 失效、报名记录按规则处理、手机号 / 学号脱敏。
- **未成年人**：如果面向未成年学生，按华为要求补充监护人同意 / 青少年模式
  说明；校园场景通常涉及，至少要在隐私政策里写清楚。
- **日志**：不打印学号、手机号、token 明文；崩溃日志不含个人信息。

## 4. 内容安全

即使不做 AI，社团简介、活动简介、消息仍然是用户生成文本：

- 发布前做长度 / 敏感词校验（服务端）；
- 管理员可下架违规活动 / 禁用社团；
- 提供举报入口（活动详情 / 社团主页）；
- 保留审计日志（谁在什么时候下架了什么）；
- 消息群发只允许负责人发给本社团报名用户，防止骚扰。

## 5. 安全自查

| 项 | 要求 | 当前状态 |
| --- | --- | --- |
| 传输 | 生产必须 HTTPS | 待部署 |
| 鉴权 | 所有写接口校验 token | 骨架已做 |
| 越权 | 云侧重新校验角色 / 社团归属 | 已做（service 层） |
| SQL 注入 | 全参数化 | SQL 适配器待实现，规范已定 |
| 密码 | 服务端哈希，不下发 | 演示用 `demo:`，上架前换 Argon2id / bcrypt |
| token 存储 | 端侧不落明文日志 | preferences 暂存，上架前迁 HUKS |
| 数据库 | 私网，最小权限账号 | 待部署 |
| 导出 | 名单导出限负责人 / 管理员 + 审计 | 待实现 |

## 6. 上架材料清单

- App 图标（分层图标）、启动图、应用名称、简介、分类；
- 截图（至少首页、活动详情、报名成功、我的页面、管理后台）；
- 隐私政策 URL、用户协议 URL；
- 隐私标签（权限、个人信息、数据共享）；
- 测试账号：
  - 学生：`student / 123456`
  - 负责人：`leader / 123456`
  - 管理员：`admin / 123456`
- 审核说明：说明三方角色、如何创建活动、如何报名、如何审核社团；
- 软件著作权 / ICP 备案 / 其他资质：按华为最新要求确认（课程项目如不对外
  商用，通常先用内测分发验证流程）；
- 版本说明 / 更新日志。

## 8. 审核被拒时的常见原因

- 隐私政策打不开 / 与实际收集不符；
- 申请了不需要的权限；
- 没有账号注销入口；
- 测试账号不可用 / 审核说明不清楚；
- 用户生成内容没有举报 / 下架机制；
- 应用内出现未备案的支付 / 诱导下载。

对应到本项目：把第 3、4、6 节的清单在 W10 前逐项打勾，基本可以避免大部分
低级问题。
