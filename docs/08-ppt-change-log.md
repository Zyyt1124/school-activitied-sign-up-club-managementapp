## 5. 答辩时怎么讲

如果老师问「仓颉到底用在哪」，按这条线回答：

1. 不是把仓颉当脚本胶水，而是把**状态机、权限、报名校验、事务编排**放在云侧仓颉服务；
2. 端侧 ArkTS 只负责 UI 和调用 HTTPS，不碰数据库；
3. 仓颉的类型系统让活动状态、错误分支在编译期就被约束；
4. 数据库交互只在 Repository 适配器里，事务边界在 service 的 `TxRunner`；
5. 上架不涉及 AI，审核重点是隐私、权限、账号注销和内容审核，路径比 AI 应用短。
